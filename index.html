Farm Management Simulation

Banana Farm Chaos

Role: Solo Gameplay Programmer & Designer

A first-person farm and retail simulation currently in development, built in Unity and C#.

The current playable build lets players:

  • Farm and harvest bananas
  • Manage and stock produce stalls
  • Handle physical cashier and change interactions
  • Build and place farm structures
  • Pick up, carry, and manage items through an inventory system
  • Interact with customers and NPCs
  • Deal with banana thieves and farm security

The project is currently in development with a playable core gameplay loop. The main goal is creating and polishing game mechanics that work well together, while also making the game fun and adding more features over time.

Note: This project is still in active development, so the current build may contain bugs, unfinished features, or temporary implementations.

Technical Architecture

  • Gameplay: ScriptableObjects, events, modular systems
  • NPCs: NavMesh navigation and AI behaviors
  • Interactions: Item pickup, inventory, and placement
  • Optimization: Object pooling and GPU instancing

Technical Art & Rendering

HLSL Shader Showcase

Environment: Unity

A collection of custom HLSL shader effects demonstrated in Unity using simple cube meshes to highlight each material's visual behavior without mesh distractions. The showcase explores real-time shader programming, procedural mathematics, and rendering techniques.

Techniques & Mechanics Explored:

  • Procedural Noise & Distortion: Dynamic mathematical noise and fractional functions for animated surfaces.
  • Vertex Displacement: Mathematical wave manipulation directly calculated in vertex shader passes.
  • UV Transformations: Panning coordinates, rotation matrices, and animated texture distortion.
  • Lighting & Rim Emission: Dot-product Fresnel calculations and stylized border emission for depth.
