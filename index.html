Farm Management Simulation

Banana Farm Chaos

Role: Solo Gameplay Programmer & Designer

A first-person farm and retail simulation currently in development, built in Unity and C#.

The current playable build lets players:

  • Farm and harvest bananas
  • Manage and stock produce stalls
  • Handle physical cashier and change interactions
  • Build and place farm structures
  • Pick up, carry, and manage items through an inventory system
  • Interact with customers and NPCs
  • Deal with banana thieves and farm security

The project is currently in development with a playable core gameplay loop. The main goal is creating and polishing game mechanics that work well together, while also making the game fun and adding more features over time.

Note: This project is still in active development, so the current build may contain bugs, unfinished features, or temporary implementations.
